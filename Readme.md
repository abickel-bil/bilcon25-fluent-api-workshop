# Fluent API Design

Welcome to BILConnect 2025!  In this workshop, we'll design and implement a simple fluent API that solves a 'real world' problem.  

This workshop is designed to be completed either synchronously or asynchronously.  It's possible that we won't cover everything in our time together, so please feel free to 'cheat ahead' and otherwise explore at your convenience.

---

What we'll cover:

- Problem decomposition and modeling
- Fluent API design, including  
  - Interface and method chaining strategies
  - Idempotent vs. non-idempotent solutions
- Implementing a fluent design

## Running the project

On any branch or step, use the following terminal command to display specific instructions for that step

Note: _command must be run from the root folder of the repository_

- `dotnet run`

## Getting started

Each step of this workshop is represented as a separate branch in the repository.

- check out the branch `overview` to continue.
